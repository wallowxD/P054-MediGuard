# Theo dõi tiến độ bàn giao

Jira là nguồn duy nhất cho ticket, sprint, assignee, priority và workflow status.

- [Mở backlog VMEC trên Jira](https://cuveetech.atlassian.net/jira/software/projects/VMEC/boards/5/backlog).
- Branch Git dùng ticket key tương ứng, ví dụ `VMEC-37`.
- Jira feature ticket link tới `specs/NNN-feature-name/spec.md` và `plan.md` khi feature cần
  workspace tài liệu riêng.
- Requirement và technical design nằm trong `specs/`; quyết định kiến trúc nằm trong
  `adrs/`.

Thư mục này chỉ có file dẫn đường này, không lưu roadmap, backlog, sprint plan, assignment
hoặc bản sao trạng thái từ Jira.
